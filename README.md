# Projektskizze Geobranch

- Wir möchten für unser Projekt ein Programm schreiben, das 3-dimensionale Voxel-Landschaften für Hintergrundbilder generiert. Als Grundlage für das Generieren wollen wir Perlin Noise nutzen. Des Weiteren wollen wir das Ganze in der Game Engine Godot umsetzen, damit wir uns nicht mit dem Rendering rumschlagen müssen.
- Wir wollen den Vorgang verfolgen das wir Noisemaps für Feuchtigkeit und andere parameter erstellen und danach basiert auf den werten auswählen was für Biome in welchen Regionen sind und diese dann generieren.
